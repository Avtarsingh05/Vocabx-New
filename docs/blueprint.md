# **App Name**: LinguaSpark

## Core Features:

- User Authentication & Profiles: Allow users to sign up and log in via email/password. Store and retrieve essential user profiles (XP, streak, level) using Firestore.
- Personalized Dashboard: Display user's current progress including XP points, learning streak, proficiency level, and daily goal completion in an engaging interface.
- Interactive Learning Module: Present new vocabulary words with their meanings and example sentences. Include a pronunciation playback feature and an option to mark words as 'learned'.
- AI Vocabulary Generator: Utilize the Gemini API tool to dynamically generate new vocabulary words, provide clear and simple explanations, and suggest synonyms and antonyms tailored to the user's current level.
- Dynamic AI Quiz System: Generate varied quiz formats, including multiple-choice questions and fill-in-the-blanks, using the Gemini API tool. Provide instant feedback and reward XP for correct answers.
- Streak & Reward System: Track consecutive days of learning to maintain and reward user streaks, fostering consistent engagement. Display achievement badges for reaching milestones.
- Basic Admin Panel: Provide a simplified administrative interface to view total registered users and monitor essential user progress data.

## Style Guidelines:

- Primary Color: Vibrant green (#56C91D) for a sense of growth and freshness, creating an inviting learning environment.
- Background Color: A soft, almost off-white green (#F2F4F0) to ensure a clean, bright, and focus-friendly light interface.
- Accent Color: Energetic yellow-orange (#F5B83D) to highlight interactive elements, provide positive feedback, and add a cheerful contrast.
- Headline and body font: 'Inter' (sans-serif) for its modern, clean, and highly readable characteristics, suitable for all UI elements and content.
- Utilize playful yet simple line-art or filled flat icons that resonate with learning, progress, and achievement, similar to popular gamified learning platforms.
- Implement a mobile-first responsive design, featuring clear content hierarchies and simple tab-based navigation (e.g., Learn, Quiz, Profile) for intuitive user flow.
- Incorporate subtle loading animations and transitions between views to provide fluid user experience feedback and prevent perceived lag.
